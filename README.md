## 🌐 Acesse o projeto

**Site público:** https://o-sentinela-davi.onrender.com

O Sentinela é um projeto desenvolvido para o HackaNAV com o objetivo de combater a desinformação, ajudando usuários a analisar sites, informações e senhas de forma clara, educativa e tecnológica.

---

## 🎯 Objetivo

Em um mundo cada vez mais conectado, a desinformação, os golpes digitais e as senhas fracas se tornaram problemas reais. O Sentinela foi criado como uma camada de apoio entre o usuário e esses riscos.

A proposta é transformar dados e dúvidas em análises compreensíveis, incentivando o uso responsável da internet, a verificação de fontes e a criação de hábitos digitais mais seguros.

> O Sentinela não substitui profissionais, fontes oficiais ou ferramentas especializadas. Seus resultados servem como orientação inicial e educativa.

---

## 🔎 Modos de verificação

### 🌐 Verificação de Sites

Permite analisar um endereço de site e identificar sinais importantes de confiabilidade e segurança.

O sistema considera fatores como:

- Uso de conexão segura (`https`);
- Domínios institucionais e conhecidos;
- Estrutura do endereço;
- Possíveis sinais de risco;
- Regras de segurança e confiabilidade.

O resultado apresenta uma pontuação e uma explicação para ajudar o usuário a interpretar a análise.

### 📄 Verificação de Informações

Permite analisar frases, notícias, afirmações ou textos que possam conter desinformação.

O sistema busca identificar:

- Afirmações conhecidas;
- Padrões de boatos, promessas exageradas ou golpes;
- Informações científicas e educacionais básicas;
- Sinais que indicam a necessidade de consultar fontes confiáveis;
- Possíveis riscos de compartilhar a informação sem confirmação.

Após a análise, o usuário pode abrir a justificativa para entender melhor o motivo do resultado.

### 🔐 Análise e Criação de Senhas

Permite verificar se uma senha é fraca, média ou forte e também criar senhas personalizadas.

A análise considera aspectos como:

- Quantidade de caracteres;
- Letras maiúsculas e minúsculas;
- Números;
- Símbolos;
- Padrões previsíveis;
- Palavras e combinações comuns.

O projeto não armazena as senhas analisadas. Mesmo assim, nunca utilize senhas reais de contas importantes em ferramentas de teste.

### 🧮 Calculadora

O Sentinela também possui uma calculadora com operações como:

- Soma;
- Subtração;
- Multiplicação;
- Divisão;
- Potenciação;
- Raiz;
- Frações.

## ▶️ Como usar

1. Abra o site: https://o-sentinela-davi.onrender.com  
2. Escolha um dos três modos principais.
3. Digite ou cole o conteúdo que deseja analisar.
4. Clique em **Iniciar Varredura**.
5. Leia o resultado.
6. Clique em **Mostrar justificativa** para entender a resposta.

Também existem exemplos clicáveis em cada modo para facilitar os testes durante a apresentação.

## 💻 Tecnologias utilizadas

- HTML
